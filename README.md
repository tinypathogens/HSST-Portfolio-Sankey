# HSST Portfolio Sankey

Interactive portfolio mapping and visualisation tool for HSST trainees.

Created by James Griffiths  
GitHub: tinypathogens

---

## Overview

HSST Portfolio Sankey allows trainees to map evidence items against:

- NSHCS HSST Curriculum Modules
- Standards of Proficiency (SoP)

The application provides:

- Interactive Sankey visualisation
- Curriculum coverage analysis
- SoP coverage analysis
- Gap analysis dashboard
- Evidence management (add/delete evidence)
- HTML export of Sankey diagrams

---

## Features

### Portfolio Mapping

Map evidence items to:

- Curriculum modules
- SoP criteria

### Sankey Visualisation

Visualise:

Curriculum → Evidence → SoP

with interactive hover information.

### Dashboard

Includes:

- Curriculum coverage
- SoP coverage
- Evidence type breakdown
- Gap analysis
- Most reused evidence items

### Evidence Management

Create and manage:

- Evidence of Activity (EOA)
- Case-Based Discussion (CBD)
- Multi-Source Feedback (MSF)
- Training Plan Events (TPE)
